## Website Architecture

The portfolio is built as a modern, component-driven Next.js application.

**Architecture:**

`Next.js` → `App Router` → `TypeScript` → `Tailwind CSS` → `Framer Motion` → `Reusable Components` → `Structured Content`

The website follows a component-based architecture with structured content to keep the portfolio maintainable and extensible.

## Getting Started

### Clone the repository

`git clone https://github.com/hetpatel4902/portfolio.git`

`cd portfolio`

### Install dependencies

`npm install`

### Start the development server

`npm run dev`

The application will be available at:

`http://localhost:3000`

---

## Production Build

Create a production build:

`npm run build`

Run the production server:

`npm start`
